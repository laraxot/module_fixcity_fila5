# Archivio legacy della documentazione Fixcity

Questa directory contiene la documentazione storica del modulo Fixcity spostata da `docs/`
durante la consolidazione (issue docs-100) che ha riportato `docs/` sotto il limite di 100 file Markdown.

- Spostata il: 2026-11-26
- Motivo: `docs/` superava le 900 unita'; restano solo ADR, contratti comportamentali,
  story attive, manuale utente e regole correnti.
- Contenuto: report storici, piani BMAD completati, wiki locale, audit, roadmap e guide obsolete.
- I file non sono cancellati: sono consultabili qui e nel git history.

Le story attive restano in `../docs/stories/`; i contratti in `../docs/contracts/`.
