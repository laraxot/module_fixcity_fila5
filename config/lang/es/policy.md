# Aviso de protección de datos

FixCity trata los datos enviados con una incidencia para recibirla, evaluarla y
comunicar sus actualizaciones. Pueden incluir datos de contacto, la ubicación
del problema, la descripción y los archivos adjuntos aportados por la persona
usuaria.

Los datos solo están disponibles para las oficinas municipales responsables y
se conservan durante el tiempo necesario para gestionar la solicitud y cumplir
las obligaciones legales. Para ejercer tus derechos, contacta con la oficina
responsable mediante los datos publicados en el portal.

Al continuar confirmas que has leído este aviso y consientes el tratamiento de
tus datos para gestionar la incidencia.
