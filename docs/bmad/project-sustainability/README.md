# Come sostenere FixCity

Dossier di discovery (BMAD + second brain). **Nessuna implementazione runtime.**

Risponde a: quali canali economici e di partnership sono coerenti con un servizio
civico multi-tenant, e dove vive la documentazione di ownership nei moduli/temi.

## Verdict

Ordine strategico consigliato:

1. **Adozione / co-funding Comuni** (B2G) — ricavo ricorrente allineato alla missione
2. **Grant pubblici / UE / filantropici** — seed e R&D (accessibilità, interoperabilità)
3. **Partner istituzionali e in-kind** — recognition trasparente, non advertising
4. **Membership ente / consorzio** — solo con soggetto giuridico e governance
5. **Donazioni** — solo con beneficiario ETS/idoneo, ricevuta, privacy
6. **Sponsorship commerciale** — eccezionale, policy pubblica, mai banner ad-tech
