# 8.18 Consolidate the current normative and procurement gate
## Story
As a **release/procurement owner**, I want current Designers Italia requirements in one evidence matrix, so that delivery and suppliers are auditable.
## Acceptance Criteria
1. The matrix covers 4.1–4.8 with reference, applicability, evidence, owner, status, gap and approval.
2. It links Epic 8, Epic 6, security, accessibility, operations and release artefacts without duplicating their source of truth.
3. Supplier and tenant acceptance criteria are explicit for accessibility, privacy, content, licensing and platforms.
4. Status distinguishes verified, owner-approved, blocked, accepted limitation and not-applicable; blockers prevent readiness.
5. It is versioned against 8.1 and ready for 7.1; 7.1 remains the release index and 7.2 the sign-off.
## Tasks / Subtasks
- [ ] Build 4.1–4.8 matrix and status vocabulary (AC: #1, #4)
- [ ] Link evidence and eliminate duplicate ownership (AC: #2, #5)
- [ ] Define procurement/supplier acceptance clauses (AC: #3)
- [ ] Add open approvals and release-blocking rules (AC: #4, #5)
