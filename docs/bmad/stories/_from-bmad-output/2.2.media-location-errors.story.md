# 2.2 Media and location failure recovery
As a citizen, I want upload/geolocation failures explained without losing my draft, so that reporting is resilient.
## Acceptance criteria
1. Invalid media is rejected with accessible, localized recovery guidance.
2. Geocoding/map failure preserves valid report data and offers manual recovery.
3. Successful submit stores only validated media/location data.
## Verification
Action tests plus browser offline/invalid-file/location-denied scenarios.
