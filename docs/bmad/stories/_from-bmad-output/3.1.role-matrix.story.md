# 3.1 PA role and denial matrix
As a municipality, I want role boundaries proven, so that staff can work safely.
## Acceptance criteria
1. Operator, supervisor, admin and citizen permissions are explicit.
2. Unauthorized reads/mutations return safe denials with no disclosure.
3. Assignment, status, comment and export checks are tested.
## Verification
Policy/Pest and candidate browser matrix.
