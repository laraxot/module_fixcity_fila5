# 5.5 Subject rights and account lifecycle

## Story

As a **citizen**, I want to exercise my data rights and request account closure,
so that the platform handles my personal data transparently without destroying
records the PA must lawfully retain.

## Acceptance criteria

1. Authenticated users can access/export only their own profile, consents, tickets and permitted attachments in a structured format.
2. The privacy area provides requests for access, rectification, restriction, portability, objection and erasure, with identity verification proportional to the request.
3. Every request records type, received-at, one-month deadline, owner, identity-check result, outcome and any approved legal reason for refusal or retention.
4. Account deletion is protected by re-authentication and uses an approved matrix: profile PII, consents, tickets, media, notifications, logs and audit evidence are deleted, anonymized or retained explicitly.
5. The user receives a localized confirmation and can see the request status; a non-self request is denied.
6. Tests prove no cross-user export, no accidental deletion of PA-required evidence and correct handling of already revoked/deleted accounts.
