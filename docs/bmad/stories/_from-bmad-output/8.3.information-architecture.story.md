# 8.3 Validate the public information architecture

## Story

As a **citizen**, I want predictable navigation and findable services, so that I
can report and track an issue without learning the site structure.

## Acceptance Criteria

1. The canonical sitemap maps home, services, report creation, tracking, personal
   area, help and legal destinations for every supported locale.
2. Navigation labels and hierarchy are consistent between header, footer, mobile
   menu and page breadcrumbs.
3. Critical tasks are validated by a keyboard/mobile navigation walkthrough.
4. Dead anchors, obsolete slugs and raw translation keys fail the IA check.

## Tasks / Subtasks

- [ ] Build the route/content IA map from actual Folio/CMS sources (AC: #1)
- [ ] Compare header/footer/mobile/breadcrumb structures (AC: #2)
- [ ] Run task-based keyboard and mobile walkthroughs (AC: #3)
- [ ] Add link/translation-key regression checks (AC: #4)
