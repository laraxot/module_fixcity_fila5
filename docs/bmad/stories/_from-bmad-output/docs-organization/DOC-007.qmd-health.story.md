# DOC-007 — Salute QMD

## Obiettivo

Allineare l'indice QMD ai documenti canonici e misurare gli orphan senza
confondere aggiornamento dell'indice con qualità dei contenuti.

## Acceptance criteria

- [ ] le collection Sixteen e documentazione sono aggiornate;
- [ ] i nuovi documenti sono ricercabili per titolo e concetto;
- [ ] gli embedding pending/orphan sono riportati;
- [ ] raw/generated sono esclusi o chiaramente classificati;
- [ ] la query recupera il canonico prima dello storico.

## Verifica

Eseguire `qmd status`, `qmd update`, `qmd embed` e query strutturate; salvare
output e data nel report. `qmd cleanup` richiede revisione separata.
