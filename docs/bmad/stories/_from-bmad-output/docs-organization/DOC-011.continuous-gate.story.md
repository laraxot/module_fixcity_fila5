# DOC-011 — Gate continuo

## Obiettivo

Impedire che il debito documentale ricresca dopo il consolidamento.

## Acceptance criteria

- [ ] esiste un healthcheck per ingressi, front matter e link;
- [ ] nuovi duplicati e root markdown oltre soglia sono segnalati;
- [ ] QMD e Graphify possono essere aggiornati con comandi ripetibili;
- [ ] la story/report indica cosa è escluso e perché;
- [ ] il readiness report BMAD collega tutti i gate e le lacune aperte.

## Verifica

Eseguire check su un modulo e un tema campione, poi su tutti i root. Salvare
report, comando, data e exit code. Nessuna dichiarazione “completo” senza evidence.
