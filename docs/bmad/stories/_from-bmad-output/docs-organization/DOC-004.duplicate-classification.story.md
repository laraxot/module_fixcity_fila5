# DOC-004 — Classificazione duplicati

## Obiettivo

Distinguere copie reali, varianti storiche e documenti con stesso nome ma scopo
diverso, scegliendo un canonico verificabile.

## Acceptance criteria

- [ ] gruppi di duplicati sono elencati per root e normalizzazione del nome;
- [ ] il canonico è scelto per contenuto e riferimenti, non solo per nome;
- [ ] gli indici concorrenti sono mappati;
- [ ] ogni candidato non canonico ha una proposta `superseded_by`;
- [ ] nessun file viene marcato superseded senza revisione del proprietario.

## Verifica

Produrre report dry-run, controllare riferimenti con `rg` e collegare l'output a
DOC-006. Non usare cancellazioni, `git mv` massivi o reset.
