# DOC-006 — Consolidamento non distruttivo

## Obiettivo

Applicare solo le classificazioni approvate, mantenendo lo storico recuperabile.

## Acceptance criteria

- [ ] esiste una migration map per ogni rename o spostamento;
- [ ] i riferimenti sono aggiornati prima del cambio di percorso;
- [ ] i duplicati sono marcati solo con link al canonico;
- [ ] raw e screenshot restano immutabili;
- [ ] ogni modifica è collegata a una story e a un decision log.

## Gate

Richiede DOC-003, DOC-004 e DOC-005. Fermarsi se esistono lock attivi o target
ambigui. Verificare con `git diff --check`, ricerca dei riferimenti e review owner.
