# DOC-010 — Qualità contenutistica

## Obiettivo

Rendere ogni docs root utile a un agente: identità, architettura, regole, flussi,
stories e limiti devono essere leggibili senza aprire centinaia di report.

## Acceptance criteria

- [ ] README spiega ownership, stack e quick start;
- [ ] indice collega le aree reali e segnala lacune;
- [ ] Cms documenta dati/blocchi/Folio, Sixteen markup/layout/parity;
- [ ] moduli business non duplicano decisioni visuali del tema;
- [ ] ogni claim di parity/WCAG ha evidence e non solo percentuale.

## Scope

Audit iniziale: Cms, Fixcity, Xot, UI, Mobile, Sixteen; estendere agli altri
perimetri usando DOC-001. Verificare link, front matter e owner review.
