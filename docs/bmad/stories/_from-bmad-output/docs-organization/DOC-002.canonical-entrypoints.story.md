# DOC-002 — Ingressi canonici

## Obiettivo

Garantire che ogni docs root abbia un README e un `00-INDEX.md` navigabile,
senza creare un nuovo indice quando ne esiste già uno.

## Acceptance criteria

- [ ] ogni root ha README e indice oppure una decisione documentata;
- [ ] l'indice dichiara canonical, evidence e legacy;
- [ ] i link Cms ↔ Sixteen sono bidirezionali;
- [ ] Mobile, UI e Xot restano coperti dagli indici aggiunti;
- [ ] nessun indice storico viene cancellato.

## Scope e verifica

Scope: `laravel/Modules/*/docs/00-INDEX.md`, `README.md`,
`laravel/Themes/*/docs/00-INDEX.md`, `README.md`. Verificare target con `test -f`,
link relativi e `git diff --check`.
