# DOC-005 — Integrità dei link

## Obiettivo

Rendere affidabili gli indici senza nascondere i riferimenti storici mancanti.

## Acceptance criteria

- [ ] i link degli indici canonici puntano a file esistenti;
- [ ] i link mancanti sono annotati con motivo e data;
- [ ] i link case-sensitive e profondità `../` sono corretti solo se il target esiste;
- [ ] i link a materiale legacy restano espliciti;
- [ ] il report indica file controllati e file esclusi.

## Verifica

Usare il link checker del repository o uno script dry-run, poi `rg` sui link e
`git diff --check`. Verificare almeno Cms, Fixcity, Xot e Sixteen.
