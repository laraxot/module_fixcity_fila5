# 6.17 Normalize legal links in runtime themes

## Story

As a **multilingual visitor**, I want every runtime legal link to preserve the
current locale and point to a real canonical destination, so that no privacy,
cookie, accessibility or legal-notice journey ends at a fixed-language URL or `#`.

## Acceptance Criteria

1. Runtime Sixteen header, footer, auth, cookiebar, consent and form surfaces use
   the shared localized URL mechanism for legal destinations.
2. No production legal link in those surfaces uses `#`, `/privacy-policy`, an
   obsolete slug, or a hard-coded unprefixed legal path.
3. Existing cookie preference behavior remains the single runtime consent path;
   neither Spatie nor a second Statikbe instance is introduced.
4. Feature or browser tests cover the supported locales and assert the canonical
   hrefs and successful responses.

## Tasks / Subtasks

- [ ] Inventory runtime legal links, excluding static reference HTML and docs (AC: #1, #2)
- [ ] Normalize only the production Blade surfaces (AC: #1, #2)
- [ ] Add localized link and response assertions (AC: #4)
- [ ] Verify the consent runtime boundary remains single-source (AC: #3)

## Dev Notes

- Use `LaravelLocalization::localizeURL()` as already used by the cookie policy
  and Tailwind footer; do not introduce a route wrapper. [Source: bmad-output/decision-log.md#Cookie Policy localizzata e baseline legale tecnica]
- Statikbe is the sole consent runtime in this project; package documentation for
  Spatie is reference only and does not authorize adding a second banner. [Source: bmad-output/research-report.md#Runtime decision]
- Do not change generated/reference fixtures merely to make a static grep green;
  the scope is runtime production templates. [Source: bmad-output/project-context.md#Core Constraints]

## Testing

- **Approach:** Pest feature assertions and a focused static scan of runtime views.
- **Key scenarios:** it/en/de/es legal hrefs, anonymous pages, cookie policy and
  privacy acknowledgement flow.
- **Per-AC verification:** AC #1/#2 → href inventory; AC #3 → single provider
  assertion; AC #4 → localized response matrix.
- **Edge cases:** unsupported locale fallback, absolute external URLs and missing
  tenant Markdown.
