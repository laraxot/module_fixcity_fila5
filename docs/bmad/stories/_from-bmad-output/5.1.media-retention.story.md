# 5.1 Media privacy and retention
As a tenant owner, I want media lifecycle rules, so that evidence is useful without becoming uncontrolled personal data.
## Acceptance criteria
1. Public/private media policy is explicit and enforced in serializers.
2. Metadata validation/scrubbing and retention/deletion are tested.
3. Access logs and failed deletion paths are observable.
## Verification
Media fixtures, policy tests and isolated storage drill.
