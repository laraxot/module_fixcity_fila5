# 5.6 Verified multilingual registration

## Story

As a **PA service owner**, I want registration and email verification to behave
consistently in every enabled language, so that an account cannot enter protected
flows through an unverified or broken localized route.

## Acceptance criteria

1. The enabled locale list is one source of truth for registration, login, verification, legal links and profile routes.
2. When verification is required, the new account is not treated as fully verified before the signed verification flow completes.
3. Verification notice, signed link, resend/throttle and failure states work in every enabled locale.
4. Production configuration explicitly documents the required mail relay and verification setting without committing credentials.
5. Feature and browser tests cover guest registration, unverified access, verified access, expired link, resend throttle and all locales.

## Tasks / Subtasks

- [ ] Reconcile `routes/web_tall.php`, Folio routes and supported locales (AC: #1, #3)
- [ ] Define login/redirect semantics for `AUTH_MUST_VERIFY_EMAIL` and social identity providers (AC: #2)
- [ ] Verify notification template, signed route and delivery configuration (AC: #3, #4)
- [ ] Add multilingual browser/feature regression matrix (AC: #5)

## Dev Notes

- Current auth routes explicitly restrict `it`/`en` while registration tests and translations include more locales. [Source: laravel/Modules/User/routes/web_tall.php; laravel/Modules/Gdpr/tests/Feature/RegistrationPageTest.php]
- `RegisterWidget` currently logs the user in from the successful-registration action; the behavior must be conditional on the approved verification policy. [Source: laravel/Modules/Gdpr/app/Actions/Registration/HandleSuccessfulRegistrationAction.php]
- External mail delivery is an operations prerequisite, not a value to invent in code. [Source: laravel/Modules/User/docs/stories/register-logout-verify-email.story.md]

## Testing

Feature tests for route names/middleware and browser tests for each locale and verification state; delivery uses an authorized test mailbox only.
