# 6.7 Cookiebar accessibility and localization QA

## Story

As a **visitor using assistive technology or a small screen**, I want the
Cookiebar and policy to be operable and understandable, so that consent is an
equal-access choice.

## Acceptance Criteria

1. The banner and policy meet the applicable WCAG 2.1 AA keyboard, focus,
   semantics, contrast, reflow and touch-target checks.
2. it, en and de render translated visible text, accessible names and policy
   links with no raw translation keys or mixed-language legal instructions.
3. `prefers-reduced-motion`, zoom to 200% and narrow mobile widths do not hide
   or disable consent controls.
4. Automated browser evidence is stored for first visit, accepted state and
   policy navigation in every supported locale.

## Tasks / Subtasks

- [ ] Audit semantic landmarks, names and focus order (AC: #1)
- [ ] Test contrast, reflow, zoom, touch target and reduced motion (AC: #1, #3)
- [ ] Run locale matrix and detect missing/raw translations (AC: #2)
- [ ] Store reproducible screenshots/logs and defect links (AC: #4)

## Dev Notes

- WCAG 2.1 AA is a project constraint for critical citizen flows.
  [Source: prd.md#NFR-003]
- The UX shell must remain familiar to Design Comuni while using the approved
  Sixteen stack. [Source: DESIGN.md#Critical components]
- The component uses native links/buttons and Alpine state; preserve progressive
  keyboard operation. [Source: Modules/Gdpr/docs/cookiebar-integration.md#Accessibilità e vincoli]

## Testing

- **Approach:** Playwright locale matrix plus axe/WCAG review and manual keyboard pass.
- **Key scenarios:** Tab/Shift+Tab, Enter/Space, screen-reader names, 200% zoom,
  320px width, reduced motion and all consent states.
- **Per-AC verification:** AC #1 → accessibility assertions; AC #2 → locale
  snapshots; AC #3 → responsive/reduced-motion runs; AC #4 → artifact check.
- **Fixtures / mocks:** clean browser contexts and it/en/de locale routes.
- **Edge cases:** long German labels, missing policy content and high-contrast mode.
