# 6.2 Theme support classification
As a platform owner, I want every theme classified, so that unsupported surfaces do not appear accidentally in production.
## Acceptance criteria
1. Barthelemy, Meetup, Sixteen and TwentyOne have supported/archive decisions.
2. Sixteen is the only active FixCity public theme unless explicitly changed.
3. Supported themes have smoke scope; archived themes have guarded routes.
## Verification
Theme inventory, route smoke and owner decision.
