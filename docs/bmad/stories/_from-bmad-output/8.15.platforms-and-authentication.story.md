# 8.15 Assess enabling platforms and authentication
## Story
As a **municipal product owner**, I want platform services assessed, so that integration decisions align with CAD requirements.
## Acceptance Criteria
1. Applicability and current state are recorded for SPID, CIE, eIDAS, pagoPA and other required platforms per tenant/journey.
2. Applicable platforms have owner, dependency, data-flow impact, fallback and acceptance evidence; non-applicable ones have rationale.
3. No integration is implemented or promised without approved decision and prerequisites.
4. Authentication and authorization remain consistent with tenant isolation and RBAC.
## Tasks / Subtasks
- [ ] Inventory platform requirements per journey and tenant (AC: #1)
- [ ] Produce applicability decisions and integration contracts (AC: #2, #3)
- [ ] Cross-check identity/RBAC and fallbacks (AC: #4)
## Dev Notes
- Current guidelines include enabling platforms; identity/RBAC is a MUST. [Source: bmad-output/research-report.md#Designers Italia: current normative requirements] [Source: bmad-output/prd.md#FR-011]
