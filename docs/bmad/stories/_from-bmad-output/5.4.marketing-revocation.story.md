# 5.4 Marketing consent revocation

## Story

As a **registered citizen**, I want to stop marketing communications immediately,
so that withdrawal is as easy as granting consent and does not delete my account.

## Acceptance criteria

1. The profile/privacy area shows the current marketing state and a clear revoke/enable action; marketing is never required for account use.
2. Revocation records an authenticated Gdpr event, timestamp and request context, invalidates active marketing consent and prevents future marketing dispatches.
3. The same control works in every supported locale and a safe unsubscribe link is available in marketing messages where applicable.
4. Authorization prevents a user from reading or changing another user's preference.
5. Tests cover grant, revoke, repeated revoke, opt-out before delivery and tenant/user isolation.

## Tasks / Subtasks

- [ ] Reuse `UpdateGdprConsentsAction`/`HasGdpr` and define the active-consent contract (AC: #1, #2)
- [ ] Connect the profile surface and localized translations (AC: #1, #3)
- [ ] Gate all marketing producers on active consent and add unsubscribe handling (AC: #2, #3)
- [ ] Add authorization, feature and dispatch tests (AC: #4, #5)
