# 8.1 Pin the current Designers Italia baseline

## Story

As a **release owner**, I want the project to identify the current Designers Italia
reference and its version, so that “compliant” means a reproducible baseline.

## Acceptance Criteria

1. The project records the current official guideline/manual URLs, access date and
   release/version used for the candidate.
2. Historical/superseded guidance is labelled as such and is not presented as the
   current normative baseline.
3. The baseline records the project exception: Bootstrap Italia is reference-only;
   runtime remains TailwindCSS + Alpine.js + Lit + DaisyUI + Flowbite.
4. Release evidence links the baseline to the design, accessibility and legal gates.

## Tasks / Subtasks

- [ ] Create a versioned Designers Italia baseline record (AC: #1, #2)
- [ ] Document stack mapping and no-Bootstrap boundary (AC: #3)
- [ ] Add baseline to release evidence and decision log (AC: #4)
