# 8.16 Govern licenses and open content
## Story
As a **release owner**, I want code, data and media rights traceable, so that publication and reuse are lawful and reproducible.
## Acceptance Criteria
1. Dependencies, content, images, documents, maps, data and icons have source/licence/attribution or an explicit review gap.
2. Third-party assets cannot publish without permission, expiry and removal owner where applicable.
3. Public attribution/licence surfaces link from appropriate localized legal/about pages.
4. Licence evidence is included in release readiness and procurement/vendor review.
## Tasks / Subtasks
- [ ] Create licence and attribution register (AC: #1)
- [ ] Define asset publication/removal review (AC: #2)
- [ ] Link public notices and release/procurement evidence (AC: #3, #4)
