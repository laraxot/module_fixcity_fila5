# 6.5 Consent-gated optional processing

## Story

As a **privacy-conscious visitor**, I want analytics and marketing processing
blocked until I opt in, so that browsing alone never creates optional tracking.

## Acceptance Criteria

1. No analytics, marketing, advertising tag, optional third-party embed or
   non-essential cookie is initialized before a positive matching consent value.
2. `__cookie_consent=false` enables only necessary behavior; configured values
   `2`, `3` and `true` enable only their corresponding categories.
3. Accepting, changing or withdrawing consent updates optional processing without
   requiring a misleading page reload or silently re-consenting.
4. The implementation has one documented event/contract for consumers and does
   not duplicate Statikbe cookie parsing in each feature.

## Tasks / Subtasks

- [ ] Inventory optional processing entry points (AC: #1)
- [ ] Centralize category decision and event contract (AC: #2, #4)
- [ ] Gate each optional initializer and support withdrawal (AC: #1, #3)
- [ ] Add negative network/browser assertions (AC: #1, #2)

## Dev Notes

- Consent must be explicit and optional processing must not be enabled by the
  banner alone. [Source: prd.md#FR-015]
- The frontend stack is Tailwind/Alpine/Lit/DaisyUI/Flowbite; do not introduce
  Bootstrap runtime. [Source: architecture.md#Technology Stack]
- Statikbe values are the configured contract; consumers must not invent a second
  storage key. [Source: Modules/Gdpr/docs/cookiebar-integration.md#Contratto di consenso]

## Testing

- **Approach:** JavaScript unit/contract tests plus Playwright network assertions.
- **Key scenarios:** clean profile, false, analytics-only, marketing-only, both,
  accept then withdraw and consent expiration.
- **Per-AC verification:** AC #1 → blocked request scan; AC #2 → value matrix;
  AC #3 → state transition test; AC #4 → event contract test.
- **Fixtures / mocks:** deterministic consent cookie and stub optional providers.
- **Edge cases:** malformed value, duplicate event, third-party script failure,
  CSP/network denial and private browsing.
