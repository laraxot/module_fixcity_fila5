# 8.4 Apply public-service content and SEO checks

## Story

As a **citizen using any supported language**, I want concise, understandable and
findable content, so that I can understand the service and act correctly.

## Acceptance Criteria

1. Critical pages have an identified purpose, audience, action and owner in each
   supported locale.
2. Visible labels, errors, legal notices and help content use plain language and
   do not expose raw translation keys or placeholder text.
3. Critical public pages have valid title, description, heading hierarchy, canonical
   locale URL and meaningful link text.
4. Legal wording remains owner-supplied and is not rewritten by this story.

## Tasks / Subtasks

- [ ] Inventory critical-page content ownership and locale coverage (AC: #1, #2)
- [ ] Add content/SEO checks to the existing candidate test strategy (AC: #3)
- [ ] Route legal content findings to owner approval rather than editing clauses (AC: #4)
