# 9.5 Close candidate security and data-lifecycle checks
## Story
As a **security/privacy owner**, I want candidate data boundaries and lifecycle controls verified, so that production does not expose tenant or personal data.
## Acceptance Criteria
1. Tenant isolation, authorization denial, private media, capability codes, rate limits and mass-assignment boundaries pass on candidate.
2. Upload metadata/privacy scrubbing, retention, deletion/export and audit evidence match approved policy.
3. Production errors, logs, traces and notifications do not expose secrets or unnecessary personal data.
4. Security headers, TLS, dependency/vulnerability review and incident escalation have evidence and owner.
## Tasks / Subtasks
- [ ] Run tenant/role/media denial matrix (AC: #1)
- [ ] Verify retention, scrub, deletion/export and audit (AC: #2)
- [ ] Inspect logs/errors/notifications and security configuration (AC: #3, #4)
