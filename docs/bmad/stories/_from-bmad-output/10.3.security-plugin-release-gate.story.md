# 10.3 Use security automation without bypassing verification
## Story
As a **security owner**, I want automated security findings triaged in the release process, so that vulnerabilities are visible and actionable.
## Acceptance Criteria
1. Security scan scope covers application dependencies, secrets, auth boundaries, uploads, tenant isolation and production configuration.
2. Findings have severity, evidence, owner, remediation/acceptance decision and due release.
3. A plugin finding is reproduced or classified locally before it blocks or passes a release.
4. No scan sends protected production data to an external service without approval.
