# 8.8 Create the continuous design improvement gate

## Story

As a **maintainer**, I want design evidence versioned and retested on each
candidate, so that FixCity improves continuously instead of freezing a one-time
visual snapshot.

## Acceptance Criteria

1. Each candidate records the guideline baseline, affected journeys, research/IA,
   content, accessibility, privacy and measurement evidence.
2. Findings are tracked with owner, severity, decision, target release and retest.
3. Approved changes can be compared against the previous candidate without deleting
   history or rewriting migrations.
4. The gate distinguishes open findings, accepted limitations and verified fixes.

- [ ] Add finding lifecycle and owner fields (AC: #2, #4)
