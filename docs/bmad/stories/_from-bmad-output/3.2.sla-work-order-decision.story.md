# 3.2 SLA and work-order semantics
As a supervisor, I want approved SLA/work-order rules, so that metrics drive real operations.
## Acceptance criteria
1. Tenant owner defines states, clocks, pauses, escalation and completion meaning.
2. KPI queries and UI use the approved vocabulary.
3. Missing configuration is visible, not silently fabricated.
