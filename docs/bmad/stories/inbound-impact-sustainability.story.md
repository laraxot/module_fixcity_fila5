# Storytelling di impatto e collaborazione sostenibile

## Richiesta / scopo
Come comunità voglio capire quale problema risolve FixCity, quale impatto produce e come collaborare o sostenerlo senza confondere servizio pubblico e pubblicità.

## Acceptance Criteria
- [ ] Sono definiti KPI di utilità, partecipazione, adozione e qualità, non solo visite.
- [ ] I dati sono aggregati, minimizzati e spiegati in linguaggio comprensibile.
- [ ] Sponsor/collaborazioni hanno criteri di trasparenza, indipendenza e accessibilità.
- [ ] Il footer può proporre sostegno solo tramite contenuto JSON approvato e CTA non manipolativa.

## Tasks / Subtasks
- [ ] Collegare missione, casi d'uso e risultati verificabili.
- [ ] Documentare alternative: grant, enti, community, sponsor etici, partnership formative.
- [ ] Definire un piano pilota e una revisione trimestrale.

## Owned File / Module Scope
Solo docs BMAD Fixcity e sezioni JSON quando la story è pronta allo sviluppo.

## Testing / Verifica
Review stakeholder, test comprensione e audit privacy/accessibilità; nessun tracking nuovo.
