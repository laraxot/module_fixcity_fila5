# Prove di fiducia dopo la promessa di segnalazione

## Richiesta / scopo
Come cittadino voglio capire cosa succede dopo aver segnalato, così la
promessa «ti ascoltiamo» diventa prova concreta e non slogan.

## Perché
Studio Asso (*fiducia dopo la promessa*): la fiducia nasce da consegna,
continuità e coerenza — non dal claim. FixCity deve narrare e mostrare
stato, tempi ed esito in linguaggio chiaro.

## Acceptance Criteria
- [ ] Definiti i «momenti di prova» post-segnalazione (ricevuta, presa in
      carico, aggiornamento, chiusura) in docs Fixcity.
- [ ] Almeno un evergreen pillar «cittadino attivo» collega il momento di
      prova a una guida/checklist (outline in Blog).
- [ ] KPI proposti: percentuale aggiornamenti entro SLA comunicato,
      comprensione stato (test qualitativo) — non bounce rate vanity.
- [ ] Nessun tracking individuale invasivo; dati aggregati e minimizzati.

## Tasks / Subtasks
- [ ] Mappare promessa FO attuale vs messaggi reali di stato.
- [ ] Outline articolo «Cosa succede dopo la segnalazione».
- [ ] Collegare a IM-FIXCITY-001 (impatto) e sustainability senza ads.

## Owned File / Module Scope
Solo docs Fixcity (+ outline Blog via IM-BLOG-005). Nessun runtime finché
readiness = CONCERNS.

## Testing / Verifica
Test comprensione con 3–5 cittadini campione (qualitativo); review privacy.
