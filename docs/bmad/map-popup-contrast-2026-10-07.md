# Contrasto popup marker mappa

Il popup dei marker è una responsabilità di presentazione del tema Sixteen.
Fixcity fornisce i dati del ticket; il tema deve garantire testo leggibile,
link distinguibile, chiusura azionabile e sicurezza del markup.

Contratto visivo: testo `#17324d` su bianco, link `#005ea8` sottolineato,
bordo `#c9d6df`, target di chiusura minimo 44px e focus ring visibile.
