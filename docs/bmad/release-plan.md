# FixCity — Release plan BMAD

## Gate 1 — Test environment

Configurare un database di test riproducibile, eseguire i test Feature Fixcity e distinguere errori ambientali da errori applicativi.

## Gate 2 — Vertical slice

Verificare con dati fixture il percorso cittadino-operatore completo, inclusa assegnazione a `responsible_id`, workflow e notifica.

## Gate 3 — Hardening

Completare policies, audit, accessibilità WCAG, i18n, performance, gestione errori, queue failure e sicurezza.

## Gate 4 — Pilota

Eseguire deploy staging, backup/restore, monitoraggio, runbook incidenti e sign-off del comune.

Mappa pubblica avanzata, API, multi-tenant, AI e app nativa restano roadmap e non devono precedere la chiusura del vertical slice.
