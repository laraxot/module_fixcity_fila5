# Perché Asso della Vendita

Fonte indice: [blog AssodellaVendita](https://www.assodellavendita.it/blog/).

FixCity non vende — ma ha lo stesso problema: passare da **promessa** a
**adozione reale** senza perdere fiducia.

## 1. Fiducia dopo la promessa (articolo)

Fonte: [fiducia-del-cliente](https://www.assodellavendita.it/fiducia-del-cliente/)

Struttura: scena → preparazione → contesto → prove/testimonianze → post-vendita
→ **tre prove** (accordo, utilità, continuità) → tabella promessa×prova×domanda
→ scheda operativa → FAQ → CTA confronto.

| Layer Asso | Domanda | FixCity |
|---|---|---|
| Promessa | Cosa ho detto? | «Segnala, ti ascoltiamo» |
| Consegna | Cosa è successo? | Stato ticket, tempi |
| Continuità | Cosa dopo? | Aggiornamenti, chiusura |
| Coerenza | Promessa = esperienza? | FO vs processo BO |

Criterio ripetuto: **una persona, una scadenza, una verifica**.

## 2. Adozione CRM per frizioni (articolo)

Fonte: [adozione-crm-venditori](https://www.assodellavendita.it/adozione-crm-venditori/)

Tesi: l’adozione fallisce se aggiornare costa più del valore restituito.
Sette cause: processo finto · troppi campi · doppia registrazione · zero utilità
· formazione solo click · manager fuori sistema · AI su dati sporchi.

Piano Asso 30 giorni: diagnosi → riduci fasi/campi → casi reali in riunione →
verifica. KPI: next step valido, tempo aggiornamento, completezza dati decisivi.

| Frizione CRM | Frizione FixCity operatore |
|---|---|
| Campi inutili | Campi ticket non usati in BO |
| Doppia registrazione | Excel + piattaforma |
| Nessun feedback | Vista carico poco chiara |
| Leader fuori strumento | Dirigente fuori flusso |

## 3. Footer / playbook come sistema

CTA tipica: «Sistema commerciale sotto controllo. Parti da dove si rompe» +
playbook. FixCity: una CTA primaria + checklist/playbook civico (hub Cms).

## Trasferire / non trasferire

Trasferire: prove post-promessa; diagnosi frizioni; playbook breve; CTA dal
punto di rottura; Existing Assets (configura prima di comprare).

Non trasferire: tono vendita; lead scoring; UTM/pixel aggressivi; gate contenuti.
