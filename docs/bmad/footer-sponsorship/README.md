# Dossier BMAD

Questo dossier risponde alla domanda: «mettere nel footer “Sostieni il nostro
progetto” e banner sponsor è una buona idea?». È documentazione di discovery:
non contiene implementazione e non modifica il contratto runtime del footer.

## Verdict

**CONCERNS — discovery sì, implementazione no.**

Partner istituzionali e sostenitori trasparenti sono la direzione giusta.
Banner commerciali in linea nel footer **non** sono la prima opzione.
Dettaglio: [recommendation.md](./recommendation.md).
