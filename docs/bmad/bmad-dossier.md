# Fixcity — BMAD dossier
## Product brief / PRD
Turn a citizen report into a transparent, geolocated and auditable PA workflow.
## Architecture / UX / security
Ticket Actions, Folio pages and XotBase Filament resources own the vertical slice; owner_id, policy and allowlisted payloads protect privacy.
## Epics and stories
Citizen report/tracking; PA assignment/SLA; timeline/follow/rating; release gates.
## Gaps / release
Privacy semantics, candidate MySQL/staging, worker/SMTP evidence, SLA rules, media retention, accessibility and sign-off remain open. Current release is NO-GO.
